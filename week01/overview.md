:::{dropdown} Text version of the animation
**Write the steps**

- A procedure is a set of steps for doing a task. Here's one for checking out a library book, in plain English.
- Python can't follow English, so we translate each step. Step 1: store the book's title in a variable named title.
- Step 2: store the patron's name in a variable named patron.
- Step 3: `print()` displays a message. The lines starting with # are comments: notes for people, which Python skips.

**Run it**

- Now we run it. Python goes top to bottom, one line at a time. Line 3 stores "Dune" under the name title.
- Line 5 stores "Maya" under the name patron.
- Line 7 looks up both names in memory and prints the message.

**Out of order**

- What if two steps trade places? Same lines of code, different order. Let's run it again from the top.
- Line 3 runs just like before.
- Line 5 asks for patron, but patron doesn't exist yet. Python stops with an error. It won't skip ahead or guess.

**Back in order**

- Put the steps back in order and it works. The computer does exactly what you write, in the order you write it.

**Key idea:** A program is a procedure: precise steps, in a precise order. Python reads your code top to bottom and does exactly what you wrote. It won't fill in missing steps or guess what you meant.
